# Arsip — kanvas "Matras"

Kanvas di folder ini menggambar arah rupa **"Matras"**, yang sudah **digantikan**
oleh arah **Digital Scoring** (shadcn/zinc). Sumber kebenaran arah yang berlaku
sekarang bukan di sini, melainkan di project Claude Design **`digiscoring`**
(`bd068c94-a5e9-4c40-9ab3-a30f50088252`), dicerminkan ke `docs/BRIEF-DESAIN.md`.

Berkas-berkas di folder ini — termasuk `sistem-desain-digiscoring-silat.html`
— dipertahankan sebagai riwayat keputusan, bukan sebagai acuan kerja. Jangan
menggambar layar baru dari kanvas ini.
